# Dune Imperium Timer

Русскоязычные личные часы на одном телефоне для базовой Dune: Imperium с Иксом, Бессмертием и совместимыми героями Кровных уз.

Приложение: https://vtkndrew.github.io/dune-imperium-timer/

## Использование

1. Укажите 2–6 игроков по часовой стрелке, выберите героев и время. Первый игрок выбирается вручную или случайно.
2. Подготовьте поле, начальные ресурсы и карты. Нажмите «Начать партию»: личные решения героев уже расходуют их время.
3. «Следующий ход» передаёт очередь. «Завершить раскрытие» пропускает игрока до сражения.
4. В сражении «Пас» приближает завершение, «Действие завершено» сбрасывает серию. Ранее пасовавший снова получает очередь. Полный круг пасов включает общий секундомер.
5. После общей подготовки нажмите «Начать следующий раунд». Первый игрок сдвигается по кругу; решения героев идут перед обычными ходами.
6. «Способность» временно включает личные часы выбранного игрока; «Готово» возвращает предыдущую очередь. Условия карт и поля подтверждает сам игрок.

Нулевой запас не исключает игрока, считается перерасход. Часы продолжаются в фоне и при закрытии: для остановки есть пауза. Отмена последнего перехода относит прошедшее после ошибки время к восстановленному таймеру. Коррекция запаса доступна на паузе. Изменение системных часов влияет на время закрытого приложения.

## Профили, итоги и статистика

Выберите существующего игрока или создайте нового через поиск. Имена уникальны; переименование в профиле отражается во всей истории и текущей игре. Палитра ограничена игровыми цветами и допускает повторы.

«Завершить партию» фиксирует время и создаёт черновик итогов. Заполните ПО, конечные ресурсы и показатели использованных дополнений по одному игроку. Можно вернуться позже и сразу начать следующую партию. Правки архивной записи также сохраняются в черновике до подтверждения.

Места предлагаются по ПО и тайбрейкам; неизвестный порядок раскрытия уточняется вручную. Полные подтверждённые результаты участвуют в общем Elo: старт 1000, K=32, попарное сравнение с усреднением. Учебную игру можно исключить из рейтинга. Исправления и удаление пересчитывают последующие значения.

В истории можно добавить партию вручную. «Без таймера» означает отсутствие измерений; иначе нужен общий личный расход каждого игрока, детализация необязательна. Статистика показывает результаты по людям и героям, средние показатели и график рейтинга. Неизвестные значения не считаются нулями.

«Экспорт JSON» сохраняет одну завершённую партию в v2. Импорт поддерживает только актуальный JSON v2, показывает привязку людей до записи, не создаёт дубликаты и требует подтверждения замены изменённой игры. Профили сопоставляются по ID или имени; привязку можно исправить. Во время разработки обратная совместимость не гарантируется: старые JSON отклоняются, устаревшая база предлагается к сбросу только после явного подтверждения. Текущий формат данных сохраняется при обычном обновлении PWA.

Данные находятся в IndexedDB этого браузера. Важные партии экспортируйте. Ошибка записи остаётся видимой и допускает повтор; конфликт вкладок требует загрузки актуальной версии. После аварийного закрытия доступно последнее успешно записанное состояние.

## PWA и установка

Откройте приложение с интернетом и проверьте в «Приложение» сообщение «Готово к работе без интернета». Затем его можно открывать офлайн. На Android используйте установку из меню браузера; на iPhone — Safari → Поделиться → На экран «Домой». Экран удерживается включённым при разрешении ОС, звук/вибрация зависят от устройства. Уведомление о нуле в фоне не гарантируется ОС; при возврате часы восстановятся корректно.

Обновление применяется только после подтверждения и успешного сохранения. Scope, manifest id, кеши и БД изолированы. У приложения нет сервера, аккаунтов и межустройственной синхронизации.

## Разработка

Node 24.21.0 (`nvm use`), зависимости закреплены в lockfile, публичный npm registry.

```sh
npm ci
npm run dev
npm run check:lockfile
npm run format:check
npm run lint
npm run lint:architecture
npm run typecheck
npm test
npx playwright install chromium webkit
npm run test:e2e
npm run test:pwa
npm run build
npm run preview
```

Локальные browser-тесты используют установленный Chrome; CI — Chromium. Dev работает на `/` без service worker; production/preview — `/dune-imperium-timer/`. Для обновления иконок отредактируйте `public/favicon.svg`, затем `npm run icons`.

## Выпуск и ручная проверка

GitHub Actions проверяет код, браузеры, PWA и публикует main в Pages. Каталог vtkndrew.github.io обновляется отдельно после проверки живого приложения. Секреты и cross-repository tokens не нужны.

Автотесты не подтверждают установку средствами мобильной ОС. На реальных Android/iPhone вручную проверить установку, авиарежим, force-close/возврат, wake lock, звук/вибрацию, скачивание JSON и выбор файла для импорта.

Некоммерческий фан-инструмент, без официального игрового арта. Справочник не является полным движком правил: 5–6 участников — гибкий таймер, а не командный режим Uprising; Автоматический соперник — Дом Хагаль — не поддерживается. Источники и границы покрытия — `docs/hero-audit.md`.

Карточки на игровом экране сохраняют места по часовой стрелке: для четырёх — 1,2 / 4,3; для шести — 1,2,3 / 6,5,4. В настройках «Случайно» выбирает первого игрока, а «Случайный герой» — свободного героя; закрытие окна до результата отменяет выбор.

`npm run test:pwa` проверяет обновление между двумя production-сборками с актуальной схемой: текущая партия, архив, профили и черновики сохраняются. Старые схемы отдельно проверяются на отказ открытия и сброс только после подтверждения; сценариев их преобразования нет.
