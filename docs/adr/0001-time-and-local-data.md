# 0001. Интервалы времени и локальные записи

Таймер должен работать после блокировки и закрытия браузера, где интервальные callbacks не гарантируются. Храним временную отметку текущего состояния и завершённые интервалы, расход вычисляем по разности времени; обновление экрана не является источником истины. Это сохраняет точный учёт и позволяет перераспределить последний ошибочный переход при отмене.

Данные остаются в IndexedDB; версия и ревизия проверяются в одной транзакции. JSON одной партии переносит историю между устройствами без сервера и сохраняет ID для будущей аналитики; совпадение имён не доказывает идентичность игроков.
