# Подтверждённые места отдельно от дополнительной статистики

Чтобы завершение партии не требовало переписывать состояние всего стола, обязательны только ПО каждого участника и подтверждённые места: разные ПО задают порядок, при равных ПО пользователь явно указывает фактические места, включая подтверждение совместных. Дополнительные показатели служат статистике, сохраняют неизвестные значения и не разрешают равенство очков; Elo воспроизводится по подтверждённым местам независимо от заполненности этих показателей. Существующие архивные места и интервалы сохраняются без пересчёта; структура данных, IndexedDB и JSON v2 остаются прежними.
