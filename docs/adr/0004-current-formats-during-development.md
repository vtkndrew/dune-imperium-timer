# Только актуальные форматы во время разработки

Приложением пока не пользуются реальные пользователи, поэтому поддержку прежних форматов не сохраняем: импорт принимает только JSON v2, автоматические миграции IndexedDB и старой палитры удалены. Это отменяет первоначальное требование обратной совместимости и уменьшает объём кода и проверок для ещё меняющейся модели.

Номер формата и проверка структуры остаются. Устаревшие тестовые данные можно удалить только после явного подтверждения в приложении; обычное обновление с актуальной схемой сохраняет данные. До появления реальных пользователей обратная совместимость не обязательна; перед публичным использованием эту политику нужно пересмотреть.
