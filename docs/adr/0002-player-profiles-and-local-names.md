# Постоянные профили отдельно от участников партий

Старый ID принадлежал карточке настройки: переименование сохраняло его, удаление места и повторное добавление создавали новый. Поэтому он непригоден для определения человека. Сохраняем ID участника для интервалов и вводим отдельный профиль; миграция объединяет старые записи по нормализованным именам в соответствии с принятой пользователем уникальностью имён.

Переименование обновляет локальные снимки во всех партиях и освобождает прежнее имя. Алиасы имён намеренно отсутствуют. В JSON v2 известные профили узнаются по ID; разные внешние ID, сопоставленные с одним локальным профилем, сохраняются как источники идентичности. V1 сопоставляется по текущему имени с возможностью исправить привязку в предпросмотре. Уже скачанный старый файл не может быть автоматически переименован.
