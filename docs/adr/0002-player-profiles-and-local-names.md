# Постоянные профили отдельно от участников партий

ID участника относится к месту в конкретной партии и связывает его с интервалами времени. Для человека используется отдельный устойчивый профиль: это позволяет менять состав, имена и привязки, не переписывая измерения. Имена профилей уникальны без учёта регистра и лишних пробелов.

Переименование обновляет локальные снимки во всех партиях и освобождает прежнее имя. Алиасы имён намеренно отсутствуют. В актуальном JSON v2 известные профили узнаются по ID; разные внешние ID, сопоставленные с одним локальным профилем, сохраняются как источники идентичности. Неизвестные профили сопоставляются по имени с возможностью исправить привязку в предпросмотре. Уже скачанный файл не может быть автоматически переименован. Миграция старых записей и импорт JSON v1 не поддерживаются согласно ADR-0004.
