# Перенос одной партии: JSON v2

UTF-8 JSON: `{ "app": "dune-imperium-timer", "formatVersion": 2, "game": ... }`. Размер до 5 MiB. Файл содержит одну завершённую архивную запись; не содержит текущую игру, черновики, другие партии или общие настройки.

Общие поля `game`: `id`, `startedAt`, `updatedAt`, `endedAt`, `round`, `players`, `winnerIds`. Участник сохраняет свой `id` для связи с временем, имя, цвет, героя, исходный запас и отдельный `profileId`. `expansions` — выбранные `ix`, `immortality`, `bloodlines`; отсутствие поля означает неизвестный состав наборов.

`finals` содержит конечные показатели по ID участников. Ключи и применимость перечислены в `METRICS` предметной модели. Неизвестный показатель отсутствует, числовой ноль и `false` являются известными ответами. `rankings` — места по ID участников; `resultsConfirmed` отмечает подтверждённые ПО и места всех участников, `sharedPlacesConfirmed` — явно принятые совместные места. `rated: false` исключает запись только из Elo. `winnerIds` соответствует месту 1 для подтверждённых итогов.

Минимальная подтверждённая запись содержит `finals[id]: { "points": 0 }` (либо другое целое ПО) и `rankings[id]` для каждого участника. Остальные показатели `finals` необязательны; импорт проверяет только введённые значения и сравнивает связанные показатели, если оба известны. При разных ПО места должны соответствовать убыванию очков; при равных ПО принимается явно подтверждённый порядок, независимо от ресурсов. Совместные места требуют `sharedPlacesConfirmed: true`. Экспорт сохраняет как минимальные, так и полностью заполненные итоги без подстановки неизвестных нулей. Структура JSON v2 и схема IndexedDB не меняются; существующие архивные места и измерения не пересчитываются.

## Измеренное и ручное время

Обычная запись сохраняет существующие интервалы, фазы, корректировки и прочие данные завершённых часов. `undo` равен null. Дополнительный `lastRevealOrder` хранит участников в порядке их последних раскрытий; позднее положение означает более позднее раскрытие. Последовательность раскрытия сохраняется как историческое событие, но не определяет итоговые места; отсутствующие события не выдумываются.

Ручная запись имеет `kind: "manual"` и не содержит вымышленных фаз или интервалов. `timing.kind` равен `none` или `summary`. `timing.duration` — известная общая длительность в миллисекундах либо null. Она не выводится из дат ручной записи.

При `none` `timing.players` пуст. При `summary` каждый участник имеет `total` в миллисекундах. При наличии детализации обязательны `turns`, `combat`, `hero`, неотрицательные и в сумме равные `total`. Нулевая измеренная длительность допустима; отсутствие измерения не является нулём.

## Поддерживаемый формат и идентичность

Экспорт и импорт используют только числовой `formatVersion: 2`. V1, неизвестные версии и чужой идентификатор приложения отклоняются до предпросмотра и записи. Конвертации старых файлов нет. До появления реальных пользователей совместимость с прошлыми форматами не требуется; версия формата сохраняется для однозначной проверки файлов.

Известный `profileId` или его ранее сопоставленный внешний ID выбирает локальный профиль даже после переименования. Иначе используется уникальное нормализованное имя; неизвестный человек создаётся при успешном импорте. Предпросмотр показывает сопоставление и позволяет выбрать другой профиль. ID участников и их интервалы сохраняются. Один профиль нельзя назначить двум участникам одной импортируемой партии.

Дубликаты сравниваются по ID партии и каноническому содержимому после сопоставления профилей. Точная копия не создаёт запись; изменённая требует явного подтверждения замены. Импорт не заменяет текущую игру или игру с незавершённым черновиком. Профили и запись сохраняются одной транзакцией. Ошибка не оставляет частично созданных людей или партий.

## Локальное хранилище

Текущая версия IndexedDB и `meta.version` — 2. Имя базы `dune-imperium-timer:v1` — исторический идентификатор хранилища, а не номер поддерживаемой схемы или JSON; переименование создало бы вторую базу вместо открытия текущей. В `app` хранятся `meta`, `settings`, `current`, `profiles`, `drafts`; ключ архива — `game.id`. Конкурирующие записи защищены номером ревизии.

Схема 1 не преобразуется: открытие прерывается без изменения данных или версии. Для устаревшей схемы либо `meta.version: 1` пользователь может явно подтвердить сброс настроек, текущей партии, архива, профилей и черновиков. Сброс атомарно создаёт пустое состояние актуальной версии. Отмена, ошибка записи или блокировка оставляют исходные данные; заблокированная операция не удаляет их позже без повторного запуска. Текущая, более новая или повреждённая неизвестная схема автоматически не сбрасывается. Другие базы, кеши и скачанные файлы не затрагиваются. Обновление PWA с актуальной схемой сохраняет записи без преобразования.
