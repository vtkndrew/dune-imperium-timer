# Перенос одной партии: JSON v2

UTF-8 JSON: `{ "app": "dune-imperium-timer", "formatVersion": 2, "game": ... }`. Размер до 5 MiB. Файл содержит одну завершённую архивную запись; не содержит текущую игру, черновики, другие партии или общие настройки.

Общие поля `game`: `id`, `startedAt`, `updatedAt`, `endedAt`, `round`, `players`, `winnerIds`. Участник сохраняет прежний `id` для связи с временем, имя, цвет, героя, исходный запас и отдельный `profileId`. `expansions` — выбранные `ix`, `immortality`, `bloodlines`; отсутствие поля в старой записи означает неизвестный состав наборов.

`finals` содержит конечные показатели по ID участников. Ключи и применимость перечислены в `METRICS` предметной модели. Неизвестный показатель отсутствует, числовой ноль и `false` являются известными ответами. `rankings` — места по ID участников; `resultsConfirmed` отмечает полные подтверждённые итоги, `sharedPlacesConfirmed` — явно принятые совместные места. `rated: false` исключает запись только из Elo. `winnerIds` соответствует месту 1 для подтверждённых итогов.

## Измеренное и ручное время

Обычная запись сохраняет существующие интервалы, фазы, корректировки и прочие данные завершённых часов. `undo` равен null. Дополнительный `lastRevealOrder` хранит участников в порядке их последних раскрытий; позднее положение означает более позднее раскрытие. Если поля нет, используем известный порядок раскрытий последнего раунда, не выдумывая отсутствующие события.

Ручная запись имеет `kind: "manual"` и не содержит вымышленных фаз или интервалов. `timing.kind` равен `none` или `summary`. `timing.duration` — известная общая длительность в миллисекундах либо null. Она не выводится из дат ручной записи.

При `none` `timing.players` пуст. При `summary` каждый участник имеет `total` в миллисекундах. При наличии детализации обязательны `turns`, `combat`, `hero`, неотрицательные и в сумме равные `total`. Нулевая измеренная длительность допустима; отсутствие измерения не является нулём.

## Совместимость и идентичность

Читаются v1 и v2. V1 требует прежнюю полную историю измерений, но не требует новых итогов. Такие записи остаются завершёнными историческими записями с неполными показателями; для Elo их нужно дополнить. Повторный экспорт идёт в v2.

Известный `profileId` или его ранее сопоставленный внешний ID выбирает локальный профиль даже после переименования. Иначе используется уникальное нормализованное имя; неизвестный человек создаётся при успешном импорте. Предпросмотр показывает сопоставление и позволяет выбрать другой профиль. ID участников и их интервалы сохраняются. Один профиль нельзя назначить двум участникам одной импортируемой партии.

Дубликаты сравниваются по ID партии и каноническому содержимому после сопоставления профилей. Точная копия не создаёт запись; изменённая требует явного подтверждения замены. Импорт не заменяет текущую игру или игру с незавершённым черновиком. Профили и запись сохраняются одной транзакцией. Ошибка не оставляет частично созданных людей или партий.

## Локальное хранилище

Имя базы `dune-imperium-timer:v1` сохранено для совместимости; версия IndexedDB и `meta.version` повышены до 2. В `app` добавлены ключи `profiles` и `drafts`; ключ архивного хранилища остаётся `game.id`. Миграция выполняется внутри транзакции обновления версии. Ошибка откатывает также версию базы; старые данные доступны для повторной попытки. Конкурирующие записи защищены номером ревизии.
