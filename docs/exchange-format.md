# Формат обмена v1

UTF-8 JSON, объект `{ app: "dune-imperium-timer", formatVersion: 1, game: ... }`. Только завершённая партия; текущая сессия и настройки интерфейса не экспортируются. В game сохраняются ID, даты, снимки игроков (ID, имя, цвет, герой, исходный запас), фазы и раунды, интервалы времени, корректировки и результат `{ winnerIds: null | string[] }`. null означает неизвестный результат; непустой массив — один/несколько победителей.

Интервалы — единственный источник статистики. Часы хранят целые миллисекунды Unix. Все поля проходят проверку структуры и связности, включая непрерывность интервалов, допустимых участников и победителей. До записи выводится preview. Одинаковый ID+содержимое — дубликат без записи; изменённое содержимое того же ID требует подтверждения замены. importedAt хранится как локальная метка архива и не меняет идентичность экспортируемой партии. Неизвестные версии отклоняются без удаления данных. Размер файла ограничен 5 MiB.
