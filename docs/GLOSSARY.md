# Глоссарий

- **Партия** — одна игра с неизменным составом участников и личными запасами времени.
- **Раунд** — ходы игроков, сражение и общая подготовка к следующему раунду.
- **Личный запас** — время игрока на всю партию, включая решения его героя; может стать отрицательным.
- **Раскрытие** — последний обычный ход игрока в раунде, включая покупки и соответствующие интриги.
- **Пас в сражении** — отказ от действия в текущей очереди. Не исключает участника из последующих очередей.
- **Серия пасов** — последовательные пасы без действий между ними; полный круг завершает сражение.
- **Первый игрок** — владелец жетона, начинающий ходы и сражение; жетон движется по часовой стрелке.
- **Общее время** — время совместного разрешения конфликта и подготовки, не расходующее личный запас.
- **Действие героя** — личное решение способности, временно получающее собственные часы.
- **Результат партии** — неизвестный результат либо явно отмеченный набор победителей.
