# Dune Imperium Timer

Согласовано 30 октября 2026. Русский офлайн-таймер на общем телефоне для базовой Dune: Imperium с Rise of Ix, Immortality и совместимыми лидерами Bloodlines. 2–6 участников (5–6 — пользовательский порядок таймера, не реализация командных правил Uprising), 4 × 30 минут по умолчанию. Автоматический соперник — Дом Хагаль — не поддерживается. Без очков, аккаунтов и синхронизации.

Имена, цвета, герои, индивидуальные лимиты; первый игрок случайно или вручную, порядок по часовой стрелке. Обычные ходы и раскрытие на личном времени; завершивших раскрытие пропускать до сражения. В сражении все снова участвуют; действие сбрасывает серию пасов, лишь N последовательных пасов завершают её. Затем общий секундомер подготовки. Новый раунд сдвигает первого игрока, выполняет решения героев, начинает его ход.

Подготовительные решения героев после запуска партии расходуют личное время. Наблюдаемые события вызываются автоматически; условия поля подтверждаются игроком либо вызываются вручную. После способности восстанавливаются предыдущая очередь и часы. Пассивные эффекты не создают лишних остановок. Нулевой остаток не исключает игрока: сигнал и перерасход.

Пауза, одноуровневая отмена перехода с перераспределением времени, корректировка запаса на паузе, звук/вибрация и wake lock. Отсчёт продолжается в фоне и при закрытии. Архив каждой партии: все интервалы, время по фазам, общий таймер, паузы, результат неизвестен либо один/несколько победителей. Результат редактируется позже. Межпартийная аналитика — будущая версия.

Экспорт/импорт одной завершённой партии в JSON: версии, устойчивые ID, проверка, preview, отсутствие дублей, явное подтверждение замены изменённой записи. Ошибка не меняет архив, импорт не затрагивает текущую игру. Одинаковые имена не объединяют людей.

Публикация разрешена: публичный vtkndrew/dune-imperium-timer, GitHub Pages /dune-imperium-timer/, карточка в vtkndrew/vtkndrew.github.io. Обратная ссылка на каталог не нужна.

Приёмка: предметные тесты, импорт/экспорт, сбои и конфликты IndexedDB, восстановление, офлайн и обновление с данными, Chromium/WebKit, 320/390px, landscape/desktop, доступные диалоги. Физические Android/iPhone проверяются отдельно.
