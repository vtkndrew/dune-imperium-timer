# Dune Imperium Timer

Обновлено по согласованному плану 1 ноября 2026. Русский офлайн-таймер на общем телефоне для базовой Dune: Imperium, Rise of Ix, Immortality и совместимых лидеров Bloodlines. 2–6 участников, по умолчанию 4 × 30 минут. 5–6 — пользовательский порядок таймера, без командных правил Uprising. Автоматический соперник — Дом Хагаль — не поддерживается. Без аккаунтов, сервера и синхронизации.

## Часы и подготовка

Места фиксированы по часовой стрелке при любой ширине экрана. Цвета: красный, жёлтый, зелёный, синий; для 5–6 доступны также голубой и серый. Собственный пикер допускает дубликаты. Уменьшение состава заменяет недоступные цвета только в настройках.

Случайный первый игрок и свободный герой выбираются равномерно. «Песчаная лента»: 2 секунды замедляющейся прокрутки, 3 секунды результата, «Готово» для быстрого закрытия. 50 оригинальных ироничных фраз идут в перемешанном порядке без повторов до исчерпания набора. Отмена, уход в фон и демонтаж до результата не изменяют настройки; уменьшенное движение исключает прокрутку.

Личные часы включают подготовительные решения героев, ходы, раскрытие и боевые действия. Раскрывшиеся пропускаются до сражения. В сражении пас не исключает игрока, действие сбрасывает серию; полный круг пасов включает общий секундомер подготовки. Следующий раунд сдвигает первого игрока. Способность временно переключает часы и возвращает очередь. Нулевой остаток даёт перерасход, не исключение.

Пауза, отмена последнего перехода с перераспределением прошедшего времени, отдельные поправки запаса, звук/вибрация и wake lock сохраняются. Последовательность раскрытия сохраняется между раундами и восстанавливается отменой.

## Профили

Профиль человека отделён от участника партии. Имена уникальны без учёта регистра и лишних пробелов. Подготовка предлагает поиск существующего профиля и создание нового; один профиль не занимает два места. Прежний состав сохраняется.

Переименование распространяется на настройки, текущую игру, черновики, архив и будущие экспорты. Старое имя освобождается, алиасы имён не сохраняются. Уже скачанные файлы не изменяются. Неизвестные профили при импорте сопоставляются по именам, известные — по ID; предпросмотр позволяет исправить привязку.

## Итоги и черновики

После подтверждения остановки фиксируется окончательное время и сохраняется черновик. Можно закрыть приложение, начать следующие игры и заполнить итоги позже. Новые черновики не входят в статистику. Правки архивной игры сохраняются отдельно: прежняя запись действует до подтверждения новой версии.

Показатели вводятся после эффектов конца игры и означают конечное состояние:

- База: ПО, пряность, солярии, вода, обычные войска в гарнизоне, влияние четырёх фракций, четыре союза, мечник, Высший совет.
- Икс: приобретённые дредноуты, оставшиеся технологии, Chaumurky.
- Бессмертие: оставшиеся образцы, этап исследования (столбец), положение на шкале тлейлаксу.
- Кровные узы: приобретённые командиры и командиры в гарнизоне.

Наборы выбираются явно. Все применимые поля новой завершённой записи обязательны, включая ответы да/нет. Пустое не равно нулю. Для гарнизонного тайбрейка обычные войска складываются с командирами; дредноуты не добавляются. Два игрока не могут владеть одним союзом или Chaumurky.

Ручная игра содержит дату, участников, героев, наборы и итоги. Без таймера измерения отсутствуют. С таймером обязателен общий расход каждого; разбивка необязательна, но при её заполнении три категории должны давать общий расход. Общая длительность вводится отдельно, если известна. Нельзя создавать фиктивные интервалы, паузы или общую подготовку.

## Места и Elo

Порядок: ПО → преимущество Chaumurky → пряность → солярии → вода → гарнизон → более позднее раскрытие. Применение правил победителя ко всем местам — адаптация приложения. Неизвестный последний тайбрейк уточняется только среди оставшихся равных участников; совместное место требует явного подтверждения. Расчёт показывает решающий критерий.

Единый Elo для всех партий на 2–6 игроков и всех наборов: старт 1000, K=32, шкала ожидания 400. Для игрока считается среднее по соперникам S−E, умноженное на K. S=1/0/0,5 по месту; E=1/(1+10^((Rсоперника−Rигрока)/400)). Изменения одновременны по рейтингам перед партией; дроби сохраняются, отображение округляется.

Учитываются полные подтверждённые результаты, в том числе ручные и импортированные. «Не учитывать в рейтинге» исключает только из Elo. Пересчёт идёт по дате проведения, при равенстве — по ID партии. Изменения, удаления и импорт задним числом пересчитывают последующие рейтинги.

## Статистика и выпуск

Общий экран: партии, победы, процент побед, Elo, средние ПО и личное время. Профиль: график и история Elo, результаты по героям, средние конечные показатели. Фильтры периода, числа участников и наборов не меняют общий Elo. У средних указана выборка; неизвестное не считается нулём, процент побед исключает неизвестные результаты. Для Elo необходимы полные подтверждённые результаты.

Экспорт/импорт одной завершённой партии: только актуальный JSON v2, устойчивые ID, проверка, предпросмотр привязок, защита от дублей, подтверждение замены. Черновики не экспортируются. Удаление подтверждается, импорт не затрагивает текущую игру. Записи IndexedDB последовательны и защищены от конфликта вкладок; автоматических миграций старых схем нет. До появления реальных пользователей обратная совместимость не является требованием. При устаревшей базе показывается предложение удалить тестовые данные; удаление выполняется только после отдельного подтверждения, атомарно и только для этого приложения. Отмена и ошибка записи оставляют данные целыми. Актуальные данные обычное обновление PWA сохраняет.

Публикация: существующий публичный vtkndrew/dune-imperium-timer и GitHub Pages. Каталожная карточка сохраняется. Проверки: предметные правила, браузеры Chromium/WebKit, ошибки записи, отказ старого JSON, подтверждённый сброс устаревшей базы и обновление с актуальными данными, офлайн, 320/390 px, landscape/desktop. Физические Android/iPhone — отдельная ручная проверка.

## Единый интерфейс и обновление часов

Все экраны и диалоги используют общие контролы shared/ui. Контейнеры обеспечивают 8 px между подписью и полем, 12 px между действиями, 16 px между блоками и 24 px после навигации. Focus-ring 2 px с offset 2 px не должен перекрывать соседние элементы. Сохраняются клавиатурное управление, возврат фокуса, касания и редактирование полей.

Окно случайного выбора сохраняет геометрию, фон, рамку, заголовок и ленту после результата. Итоговая фраза и «Готово» заранее участвуют в layout, скрытые через visibility:hidden; их высота не измеряется и не фиксируется. На результате видимость включается, частицы замирают. При reduced-motion результат появляется сразу без ленты в движении и без частиц. Первый игрок обозначается песчаным червём, победители — кубком, с текстовыми пояснениями.

Скрытый файловый input монтируется только в списке истории. Отмена не меняет данные; повторный выбор того же файла обрабатывается. В useTable нет периодического React-состояния текущего времени: визуальные тики принадлежат игровому экрану, проверка истечения запасов работает отдельно и сохраняется при открытой истории или статистике. После возвращения из фона показания сразу восстанавливаются по временным отметкам. Отсутствие лишних обновлений проверяется React Profiler и MutationObserver, а не подсветкой DevTools.

Проверки UI: Chromium и WebKit, 320/390 px, горизонтальный и широкий экран; пустые/заполненные/ошибочные/заблокированные состояния, длинные имена, фокус и касания. Геометрия окна случайного выбора сравнивается до и после результата, включая сохранение того же DOM-элемента ленты. Модели партий, схема IndexedDB и JSON v2 этим изменением не затрагиваются.
